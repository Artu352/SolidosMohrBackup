Sección de Resultados y Fórmulas Desarrolladas
Módulo de Elasticidad Cortante (G)
G = E / [2(1 + ν)]
G = 26.316 GPa
Ley de Hooke — Esfuerzo Normal X (σx)
σx = [E / (1 - ν²)](ϵx + νϵy)
σx = 55.067 MPa
Ley de Hooke — Esfuerzo Normal Y (σy)
σy = [E / (1 - ν²)](ϵy + νϵx)
σy = -4.581 MPa
Ley de Hooke — Esfuerzo Cortante (τxy)
τxy = G · γxy = [E / (2(1 + ν))]γxy
τxy = 13.158 MPa
Deformaciones Unitarias (ϵx, ϵy, γxy)
ϵx = (σx - νσy)/E  |  ϵy = (σy - νσx)/E
ϵx = 800 μϵ, ϵy = -300 μϵ, γxy = 500 μϵ
Centro (C) y Radio (R) del Círculo de Mohr
C = (σx + σy)/2  |  R = √[((σx - σy)/2)² + τxy²]
C = 25.24 MPa, R = 32.58 MPa
Esfuerzos Principales (σ1, σ2) y Puntos A, B
σ1 = C + R  |  σ2 = C - R
σ1 = 57.82 MPa, σ2 = -7.33 MPa
Esfuerzos Transformados (σx', σy', τx'y')
σx',y' = C ± [(σx-σy)/2]cos(2θ) ± τxysen(2θ)
σx' = 0, σy' = 0, τx'y' = 0
